# Artificial Inquiries - Exercice 10.a

## Room for Improvement

### Informations

- **Task ID :** A3
- **Type de tâche :** Génération de code
- **Modèle utilisé :** Claude-Code

### Problème rencontré

Le résultat obtenu était en partie correct, mais il ne correspondait
pas complètement à ce qui était demandé. Le code proposé devait être
modifié avant de pouvoir être utilisé dans le projet.

Certains éléments étaient trop généraux et ne correspondaient pas
exactement à la structure du projet.

### Pourquoi ?

Le prompt ne donnait pas assez d'informations sur le projet et sur
la façon dont le code devait être organisé. Le modèle devait donc
faire certaines suppositions.

Cela a donné une réponse correcte sur le principe, mais pas
totalement adaptée au contexte.

### Amélioration possible

Pour obtenir un meilleur résultat, il faudrait donner plus
d'informations dans le prompt, par exemple :

- la structure du projet ;
- les fichiers concernés ;
- les technologies utilisées ;
- les contraintes à respecter ;
- un exemple du résultat attendu.
